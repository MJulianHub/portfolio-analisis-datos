# Portafolio de Análisis de Datos

Portafolio profesional de proyectos de análisis de datos y Business Intelligence, enfocados en la preparación, transformación, análisis y visualización de datos.

Los proyectos integran herramientas como Power BI, DAX y Power Query para desarrollar dashboards interactivos, analizar indicadores de desempeño, identificar tendencias y presentar información relevante para la toma de decisiones empresariales.

## Proyectos

### 1. Apple | Análisis Financiero y Comercial

Dashboard desarrollado en Power BI para analizar el desempeño financiero y comercial de Apple durante los años fiscales 2023–2025.

**Incluye:**
- Resumen ejecutivo con indicadores clave de desempeño (KPI).
- Análisis de ventas por categoría de producto y región.
- Evaluación de márgenes de rentabilidad, costos y gastos operativos.

**Herramientas:** Power BI, DAX y Power Query.

[Ver proyecto y capturas](apple-power-bi/README.md)

### 2. Medallero Olímpico | Análisis Histórico con Power BI

Mi primer dashboard en Power BI, enfocado en el análisis histórico de los Juegos Olímpicos desde 1896 hasta París 2024, utilizando un conjunto de aproximadamente 20.000 registros.

**Incluye:**
- Análisis del medallero general por país.
- Comparación de resultados por género: femenino y masculino.
- Análisis de medallas por disciplina deportiva.
- Visualizaciones interactivas para identificar patrones y comparar resultados históricos.

**Herramientas:** Power BI, Power Query y DAX.

**Fuente de datos:** *Olympic Medalist Dataset (1896–2024)*, publicado por `sainsdataid` en GitHub a partir de datos de OlympAnalyt.

[Ver proyecto y capturas](medallero-olimpico/README.md)
